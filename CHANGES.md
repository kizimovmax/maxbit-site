## 0.3.2 (модуль) — 15.10.2026 — обновление одним запросом
- Точка обновления: `POST /maxbit/v1/update/fetch {url, sha256, type, seed?}` — сервер сам скачивает ZIP по https-ссылке (wp_safe_remote_get: только публичные адреса и стандартные порты; до 20 МБ), сверяет обязательную SHA-256, делает резервную копию и ставит штатным установщиком. Один запрос вместо передачи файла кусками.
- `POST /maxbit/v1/update/cleanup` — удаление остатков `*.part`/`*.zip` из `wp-content/maxbit-updates/`; `status` показывает остатки (`staging`) и список возможностей.
- Защита: если текущая папка темы/модуля — символическая ссылка, обновление отклоняется (штатный установщик удаляет старую версию «сквозь» ссылку — так был потерян локальный исходник темы при тесте; восстановлен из пакета 0.5.0 байт‑в‑байт).
- Версия «до» читается из style.css, а не из кэша тем.
- `scripts/deploy-package.py --fetch-url … --emit-js` печатает JS для одного запроса из админки.
- Проверено локально: отказы (нет sha, не https, закрытый адрес, неверная sha, чужой пакет, ссылка на симлинк) и установка темы 0.5.0 по ссылке (резервная копия, версия, страница 200). check.sh 146/146. Тема не менялась (0.5.0).
