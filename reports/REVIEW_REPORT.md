## 3. Известные ограничения сборки 2.2
1. Нет браузерных снимков 1440/390, редактора и состояний формы; нет Lighthouse. Процедура — README_RUN «Браузерные проверки». Демо-страница собрана из HTML-снимков работающего WordPress (`scripts/snapshots.sh` + `build-demo.py`), это не доказательство вёрстки.
2. Физические файлы `uploads` не защищены допуском (A08, MB-02).
3. Импорт WXR не проверен; пагинация на объёме >2 страниц — ручная проверка.
4. `PHP Deprecated: seems_utf8` в журнале — от SQLite-плагина при WP 7.1; на MySQL не воспроизводится.
5. Локальный `wp-config.php` читает `MAXBIT_ENV`/`MAXBIT_FORM_MODE`/`MAXBIT_DELIVERY_TEST_URL` из окружения — только для проверок; на хостинге конфиг не меняется, среда — из настройки модуля (`staging`).
6. Проверка на MariaDB 10.11, а не на MySQL 8.0 Webhost1; установка через веб-панель, `.htaccess`/nginx-правила и HTTP-авторизация стенда — проверяются на сервере по чек-листу README_DEPLOY_WEBHOST1 §5.
7. Почта на стенде отключена намеренно (в т.ч. сброс пароля) — переключатель в «MAXBIT → Среда».

## 4. Готовность
- **К установке на dev.maxbitpro.ru**: готово — установочные ZIP проверены установкой на MariaDB; инструкция README_DEPLOY_WEBHOST1.
- **К повторной приёмке**: готово — все автоматизируемые критерии подтверждены запуском; браузерные (A16–A18, части A05/A06/A11) проверяются на стенде.
- **К публичному выпуску**: **не готово** — не выполнены условия docs/02 §3 (хостинг с MySQL, HTTPS, контакты, юридические тексты, реальный маршрут обращений, аналитика, резервные копии), не утверждены тексты и кейсы, не проведены браузерные проверки.
