## 3. Установка на dev — порядок (выполняю сам из админ-сессии владельца во встроенном браузере)

Пакеты: `https://raw.githubusercontent.com/kizimovmax/maxbit-site/main/packages/`
- `maxbit-core-0.4.1.zip` — SHA-256 `811eeb166fee82fb8f38556f07635e9fc0504f55bdcc7002e15ffe1afaa0003e`
- `maxbit-theme-0.6.0.zip` — SHA-256 `515ee866d869d51405b088cb9a1960e524ba69f75ea9d707953604b58ae81128`

1. `GET /wp-json/maxbit/v1/update/status` — убедиться: plugin 0.3.2, theme 0.5.2, staging пуст.
2. Резервная копия содержимого главной (ID 12) через REST → reports/graphite-0.6.0/dev/home-12-before.json (текущая SHA-256 содержимого `f2a8034ea1c0ad821de612ba4938d4a09f6d93a86ba05dc23bb5de5c726000b4`, 15 548 символов).
3. `POST update/fetch {url: …/maxbit-core-0.4.1.zip, sha256, type: "plugin"}` — модуль первым (в нём шорткоды и наполнение, которые нужны теме). Сервер делает копию 0.3.2 сам.
4. `POST update/fetch {url: …/maxbit-theme-0.6.0.zip, sha256, type: "theme"}` — копия 0.5.2 делается сервером.
5. `POST update/seed` — создаёт недостающее: политика/согласие (если нет), страницы цен (private + draft), метки роль/процесс/система, пункт меню. Существующие страницы не перезаписывает.
6. Правка главной: `scripts/graphite-0.6.0-home.js` вставляет секцию самодиагностики перед «Разберитесь сами» — только если SHA содержимого совпадает с п. 2; результат записывается через REST `pages/12` и сверяется повторным чтением.
7. Проверка на dev: status (0.4.1 / 0.6.0), главная и 3 внутренние — 200, noindex, PHP-ошибок нет; снимки 1440/390; самодиагностика тестовой заявкой (режим LOCAL_TEST/без CRM сохраняется); `/price/<ключ>/` по ключу из настроек; cookie-баннер (в dev Метрика не грузится в любом случае).
8. Темп: не больше одного запроса в 2–3 с (BitNinja ставит капчу после ~40 быстрых запросов).

Откат: `update/apply` копиями, которые сервер сделал в п. 3–4 (theme-0.5.2-*, plugin-0.3.2-*), либо пакеты 0.5.2/0.3.2 из `packages/`; главная — запись содержимого из home-12-before.json.

Что меняется из существующих данных на dev: содержимое главной (одна вставленная секция, обратимо), новые страницы и метки (добавляются). База, wp-config.php, остальное содержимое не трогаются.
