## 6. Почему установка заняла столько времени

Единственный мой канал на dev — панель браузера, в которой каждый вызов ограничен по размеру. Пакет 270 КБ передавался через точку обновления модуля кусками по 24 000 символов base64 (19 кусков); один кусок при переносе исказился, сервер по проверке SHA-256 отклонил сборку и удалил части, повторная передача шла ~10 минут на кусок. Моя первоначальная оценка времени (≈1 минута на кусок) была неверной — приношу извинения. Правильное решение — отдать ZIP владельцу на ручную загрузку — заняло пару минут.

**Предложение на будущее (на согласование, отдельным пунктом):** в модуле 0.3.2 добавить в точку обновления режим «скачать подписанный пакет по ссылке» (например, из GitHub Releases или приватной ссылки с проверкой SHA-256). Тогда обновление темы — один запрос из админки, без передачи файла через чат и без ручной загрузки.
