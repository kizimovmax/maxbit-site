## 4. Закрытые материалы — техническая модель

- Содержимое — непубличный тип записей `mb_material` (не в поиске, RSS, REST, sitemap, oEmbed).
- Ссылка: случайный токен 256 бит (`random_bytes(32)`, base64url). В базе хранится только SHA-256 токена + материал + номер заявки + дата + статус (действует/отозвана) + необязательный срок.
- Выдача: в карточке заявки кнопки «Ссылка на КП» / «Ссылка на презентацию» → ссылка показывается один раз для копирования; список выданных ссылок с кнопкой «Отозвать». Отправка клиенту — вручную.
- Ответ: проверка токена на сервере до вывода; без токена, с неверным или отозванным — 404 без содержания. Заголовки `X-Robots-Tag: noindex, nofollow, noarchive`, `Cache-Control: private, no-store`, `Referrer-Policy: no-referrer`; Метрика и сторонние скрипты на этих страницах не подключаются; в OG/JSON-LD/canonical токена нет. `robots.txt`: `Disallow: /materialy/`.
- Проверки: без токена / неверный / верный / отозванный, повтор после прогрева кеша, поиск, sitemap, RSS, REST, исходный код открытых страниц.

## 5. SEO и нейро-поиск

- Title / H1 / description всех 20 страниц — из `seo-map.json` (хранятся в полях страницы, правятся в админке).
- Разметка: Organization (без телефона; почта после проверки; sameAs — каналы), WebSite, BreadcrumbList везде; Article у публикаций и кейсов (автор — MAXBIT, пока авторство Максима не подтверждено); Service у решений и обзора Б24; FAQPage только из видимых вопросов; Person на `/osnovatel/`. Без AggregateRating и звёзд.
- OG: автогенерация картинок «Графит» для всех страниц, включая кейсы; у закрытых материалов OG нет.
- llms.txt (только production): разделы «Решения», «Проекты», «Практика», «Битрикс24», контакты-боты.
- Перелинковка по `internal-links.json`: в тексте, в «Проектах по теме» на решениях, в «Связанных решениях» на кейсах — без «стены ссылок».
- Аналитика: `form_success`, `request_kp`, `request_presentation` (после подтверждённого сохранения), `telegram_bot_click`, `max_bot_click`, `bitrix24_features_click`, `bitrix24_create_click`. Без имени, контакта, текста и токенов. На dev боевая отправка выключена.
