1. Содержание: `POST /wp-json/maxbit/v1/update/content-restore {"backup":"maxbit_v4_backup_20261026_120152","confirm":"restore"}` — возвращает 10 записей к прежнему виду, созданные v4 записи переносит в корзину, восстанавливает опции и главное меню.

## Аналитика и счётчики — что готово и что подключить (27.10.2026)

**Уже есть в коде:**
- Яндекс Метрика загружается только после согласия посетителя на cookie. На закрытых материалах (/materialy/) не подключается.
- Цели:
  - заявки: form_start, form_success, lead_submit_accepted, lead_submit_error, request_kp;
  - мессенджеры и почта: telegram_bot_click, max_bot_click, telegram_channel_click, max_channel_click, email_click;
  - материалы: file_download, quiz_open_hero, quiz_complete, review_open;
  - ошибки: page_404.
  - Персональные данные и токены в цели не передаются.
- Поле для кода подтверждения Яндекс Вебмастера в настройках MAXBIT.

**Нужно подключить (до запуска на основном домене):**
1. Яндекс Метрика — создать счётчик для maxbitpro.ru (Вебвизор по желанию), вписать номер в настройки MAXBIT, создать в Метрике цели-события с именами выше. Для проверки на dev — отдельный тестовый счётчик, чтобы не смешивать данные.
2. Яндекс Вебмастер — подтвердить сайт (мета-тег), добавить sitemap, задать главное зеркало (https, без www или с www).
3. Google Search Console — подтвердить сайт и добавить sitemap. Нужно добавить поле подтверждения для Google — сделаю.
4. Google Analytics не рекомендую без отдельного решения: передача данных за рубеж требует уведомления Роскомнадзора; для сайта MAXBIT достаточно Метрики.
5. Пиксели рекламы (VK Реклама, Яндекс Директ) — только если планируется реклама; подключаются через то же согласие на cookie.
6. В политике обработки данных и тексте cookie-баннера должны быть перечислены все подключённые сервисы.

Счётчики на dev включаются только тестовые; боевые — при переносе на основной домен.
